# 热点新闻简报 (Hotspot Briefing)

生成指定热点主题的实时新闻简报，使用中文输出，包含四个主要部分。支持自定义热点关键词，适用于国际局势、科技动态、财经事件等各类热点追踪。

**可用工具**：kimi_search（搜索新闻）、exec（执行命令/脚本）

## 概述

本技能创建全面的热点主题简报，用户需提供：
1. **热点主题** - 简报的核心关键词/主题（如：俄乌冲突、美联储议息、AI技术突破等）
2. **目标邮箱** - 接收简报的邮箱地址

简报包含四个主要部分：
1. **动态总结** - 热点一句话概览
2. **最新事件** - 至少10条可信事件（标题、时间、来源、链接、中文摘要）
3. **各方观点** - 相关方/专家/市场的最新表态
4. **影响分析** - 对关联领域的影响评估

**所有输出内容为中文**

## 重要提示

**⚠️ 必须发送邮件**：生成报告后，**必须使用 exec 工具执行邮件发送脚本**，将PDF发送到指定邮箱。这是任务的强制要求，不可跳过。

**📋 执行日志记录**（可选）：每步操作可记录到日志：
```
echo "hotspot-briefing+log+$(date +%Y-%m-%d-%H-%M)" >> ~/.local/log/hotspot-briefing/workrecord.log
```

**发送命令模板**（使用相对路径或环境变量）：
```
exec:
{
  "command": "python3 scripts/send_email.py --to <目标邮箱> --subject '<主题>简报 | MM-DD HH:MM' --body '简报PDF已生成，请查看附件。' --attachments /tmp/hotspot_briefing.pdf"
}
```

**环境变量配置**（推荐）：
- `HOTSPOT_SKILL_DIR` - Skill 根目录（自动检测，通常无需设置）
- `HOTSPOT_SMTP_JSON` - SMTP 配置 JSON 字符串
- `HOTSPOT_SMTP_CONFIG` - SMTP 配置文件路径
- `CHROME_PATH` / `PLAYWRIGHT_PATH` - Chrome/Playwright 路径（跨平台需要时设置）

**发送成功后**：
- 必须报告"邮件已成功发送到 <目标邮箱>"
- 确认发送的主题和附件文件名
- 如发送失败，必须重试并报告失败原因

## 工作流程

### 1. 确定热点主题

**从用户输入中提取**：
- **主题名称**：简报的核心主题（如：俄乌冲突、美联储利率决议、ChatGPT新功能等）
- **时效范围**：新闻时间范围（默认3小时，用户可指定1天/7天）
- **目标邮箱**：接收简报的邮箱地址

**主题分类建议**：
| 类别 | 示例主题 | 搜索关键词 |
|------|----------|------------|
| 国际局势 | 俄乌冲突、中东局势 | Russia Ukraine war, Israel Hamas conflict |
| 财经金融 | 美联储议息、股市暴跌 | Fed interest rate decision, stock market crash |
| 科技动态 | AI突破、芯片发布 | AI breakthrough, new chip launch |
| 突发事件 | 自然灾害、安全事故 | earthquake, accident |
| 政策动向 | 新政发布、监管变化 | new policy, regulation |

### 2. 获取实时新闻（必须使用 kimi_search）

**重要：使用 kimi_search 工具获取指定时间范围内的新闻**

根据主题生成多语言搜索查询：

```
kimi_search:
{
  "query": "<英文主题关键词> latest news last <时间范围>",
  "freshness": "<pd参数>"
}
```

```
kimi_search:
{
  "query": "<中文主题关键词> 最新消息 今天",
  "freshness": "<pd参数>"
}
```

**freshness 参数说明**：
| 时效要求 | freshness值 | 说明 |
|----------|-------------|------|
| 3小时内 | 不使用 | 手动筛选 |
| 1天内 | "pd1" | 过去1天 |
| 7天内 | "pd7" | 过去7天 |
| 1月内 | "pm1" | 过去1月 |

**搜索策略**：
- 中英文关键词各搜索一次
- 根据主题添加相关子话题（如俄乌冲突需搜索NATO、制裁、能源等）
- 确保获取至少10条有效新闻

### 3. 整合新闻内容（中文）

**⚠️ 重要提示：必须从搜索结果中整理至少10条最新新闻事件**

将搜索结果整合为四个部分：

**第一部分：动态总结**
- 用一句话总结当前热点态势
- 突出最关键的变化和趋势

**第二部分：最新事件（至少10条）**
- 仔细阅读搜索结果，提取所有相关新闻
- 如果搜索结果超过10条，优先选择最新、最重要的10条以上
- 如果搜索结果不足10条，尝试更换搜索关键词再次搜索
- 每条事件必须包含：标题（中文）、发生时间、来源、链接、中文摘要（100-150字）

**新闻事件格式示例**：
```
标题：[中文标题，简洁明了]
时间：YYYY-MM-DD HH:MM
来源：媒体名称
链接：https://...
摘要：[100-150字中文摘要，概括事件要点和影响]
```

**第三部分：各方观点**
根据主题类型，整理相关方的表态：

| 主题类型 | 关注的相关方 |
|----------|--------------|
| 国际冲突 | 冲突双方、大国立场、国际组织 |
| 财经金融 | 央行/政府、投行/分析师、市场反应 |
| 科技动态 | 公司官方、行业专家、竞争对手 |
| 突发事件 | 政府部门、救援组织、目击者 |
| 政策动向 | 政策制定方、受影响行业、专家解读 |

**第四部分：影响分析**
根据主题类型，分析影响领域：

| 主题类型 | 影响维度 |
|----------|----------|
| 国际冲突 | 地缘政治、能源价格、金融市场、难民人道 |
| 财经金融 | 股市、债市、汇率、大宗商品 |
| 科技动态 | 行业格局、竞争态势、用户影响、投资方向 |
| 突发事件 | 直接损失、次生影响、应对措施 |
| 政策动向 | 相关行业、市场反应、长期趋势 |

### 4. 填充 HTML 模板

使用 `assets/template.html` 中的变量填充内容：

**模板变量列表**：

| 变量名 | 说明 |
|--------|------|
| `{{THEME}}` | 热点主题名称 |
| `{{TIMESTAMP}}` | 生成时间 |
| `{{SUMMARY}}` | 动态总结 |
| `{{EVENT1_TITLE}}` ~ `{{EVENT10_TITLE}}` | 事件1-10标题 |
| `{{EVENT1_TIME}}` ~ `{{EVENT10_TIME}}` | 事件1-10时间 |
| `{{EVENT1_SOURCE}}` ~ `{{EVENT10_SOURCE}}` | 事件1-10来源 |
| `{{EVENT1_LINK}}` ~ `{{EVENT10_LINK}}` | 事件1-10链接 |
| `{{EVENT1_SUMMARY}}` ~ `{{EVENT10_SUMMARY}}` | 事件1-10摘要 |
| `{{STAKEHOLDER1_NAME}}` / `{{STAKEHOLDER1_VIEW}}` | 相关方1名称/观点 |
| `{{STAKEHOLDER2_NAME}}` / `{{STAKEHOLDER2_VIEW}}` | 相关方2名称/观点 |
| `{{STAKEHOLDER3_NAME}}` / `{{STAKEHOLDER3_VIEW}}` | 相关方3名称/观点 |
| `{{STAKEHOLDER4_NAME}}` / `{{STAKEHOLDER4_VIEW}}` | 相关方4名称/观点 |
| `{{IMPACT_AREA1}}` / `{{IMPACT_ANALYSIS1}}` | 影响领域1及分析 |
| `{{IMPACT_AREA2}}` / `{{IMPACT_ANALYSIS2}}` | 影响领域2及分析 |
| `{{IMPACT_AREA3}}` / `{{IMPACT_ANALYSIS3}}` | 影响领域3及分析 |

### 5. 转换为PDF并发送邮件

**使用合并脚本一次性完成PDF转换和邮件发送：**

```
exec:
{
  "command": "python3 scripts/convert_and_send.py /tmp/hotspot_briefing.html <目标邮箱> '<主题>简报 | MM-DD HH:MM'"
}
```

**替代方案（分开执行）**：
- 转换PDF：`node scripts/html_to_pdf.js <input.html> <output.pdf>`
- 发送邮件：`python3 scripts/send_email.py --to <recipient> --subject <subject> --attachments <pdf>`

**环境变量配置**（跨平台/非标准环境时使用）：
- `HOTSPOT_SKILL_DIR` - Skill 根目录
- `NODE_PATH` - Node.js 可执行文件路径
- `CHROME_PATH` - Chrome/Chromium 可执行文件路径
- `PLAYWRIGHT_PATH` - Playwright 模块路径

## 时间检查要求

**⏰ 执行前必须先获取当前系统时间**：
1. 调用 `session_status` 工具获取当前日期时间
2. 根据用户要求或默认规则确定时效范围
3. **严格排除超过时效范围的旧新闻**
4. 在报告顶部明确标注："数据截止时间：[获取的系统时间]"

**📅 默认时效规则**：
- 默认：最近3小时内
- 可选项：1天内（pd1）、7天内（pd7）、1月内（pm1）
- 如果搜索结果中没有时效范围内的内容，必须在报告中注明

## 注意事项

- **必须从用户输入中提取主题和邮箱**，不能假设固定值
- **必须使用 kimi_search** 获取最新新闻，使用适当的 freshiness 参数
- **至少10条最新事件**，每条包含标题、时间、来源、链接、中文摘要
- **根据主题灵活调整**各方观点和影响分析的内容
- **所有输出必须是中文**
- 邮件主题使用中文："<主题>简报 | MM-DD HH:MM"
- 时效性强的主题（如突发事件）优先使用3小时范围
